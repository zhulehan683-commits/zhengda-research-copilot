# 问卷说明（演示）

1. 过去一个月是否购买过现制咖啡？（筛选题）
2. 你是否知道自带杯折扣？（是/否/不确定）
3. 如果自带杯折扣为 2 元，你重复购买的意愿有多高？（1–5）
4. 如果自带杯折扣为 5 元，你重复购买的意愿有多高？（1–5）
5. 我对价格比较敏感。（1–5，反向题示例）
6. 我愿意为环保多走 2 分钟。（1–5）
7. 我最常购买咖啡的渠道（多选：A 校内店 / B 校外店 / C 外卖 / D 便利店）。
8. 年龄与性别（仅用于样本结构描述，不进入主模型）。

问卷顺序、跳题与编码以 `data-dictionary.csv` 和 `data-preflight-schema.json` 为准。反向题不在采集时改分，清洗阶段显式执行并留痕。
