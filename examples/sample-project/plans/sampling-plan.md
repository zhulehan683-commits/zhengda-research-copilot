# 抽样计划（演示）

| 项目 | 内容 |
|---|---|
| 目标总体 | 本校过去一个月购买过现制咖啡的本科生 |
| 抽样框 | 两个已获授权社群 + 一个线下摊位 |
| 招募 | 自愿参与，匿名，可随时退出 |
| 目标样本 | 60 份有效问卷（按 20% 无效上浮到 75 份） |
| 样本量依据 | 演示：比例精度法，p=0.5，margin=0.11，95% 置信度，约 80；实际应重新计算 |
| 推断边界 | 只能描述本渠道受访者，不声称代表全校或全国 |
| 偏差 | 社群成员、咖啡常客、愿意扫码者可能过度代表 |
| 质量监控 | 每日记录发放渠道、回收数、重复 IP/设备不可用则记录缺失 |
