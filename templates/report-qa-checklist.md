# 研究报告质量检查清单（模板）

## 研究逻辑
- [ ] 研究问题与目标总体明确，章节与分析均服务于研究问题。
- [ ] 文献、政策与市场事实可追溯到原始发布方，已记录时间与口径。
- [ ] 调查工具、抽样框、样本量依据、预测试与实施过程有真实记录。

## 数据与统计
- [ ] 原始数据只读保存，脱敏数据用于分析，清洗规则与样本变化可复现。
- [ ] 每个关键结果有分析脚本、执行命令、退出码、数据版本和结果表。
- [ ] 方法前提、诊断、效应量/不确定性、稳健性与局限已说明。
- [ ] 没有把便利样本写成概率样本，也没有把相关关系写成因果结论。

## 结论与建议
- [ ] 每条核心结论绑定研究问题、数据/图表、口径和限制。
- [ ] 建议写明执行主体、具体动作、资源前提、时间和衡量指标。
- [ ] 探索性结果与确定性结论明确区分。

## 格式与诚信
- [ ] 正文、表格、图表、摘要、PPT 和答辩数字一致。
- [ ] 匿名、页数、附件、地图、引用与提交格式按当届规则复核。
- [ ] AI 使用台账与当届披露要求一致。
- [ ] 不含虚构问卷、来源、引用、模型结果或未经授权的个人信息。
