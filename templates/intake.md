# 启动 Intake（模板）

首次使用时按本表填写；未知字段明确标注"待核验"，不编造。

```text
选题：
研究对象/总体：
地域与时间：
比赛年份/组别/赛区：
学校与本校通知：
个人报名与知识赛状态：
截止时间：
当前阶段：registration / knowledge / team / topic / desk_research / design / pilot / fieldwork / cleaning / analysis / report / defense / submission
已有数据与来源：
计划获取的数据：
团队人数与能力模块：研究设计 / 数据与编程 / 视觉与排版 / 文稿与质控（可由一人兼任）
预算与可支配时间：
用户自定义想法/要求：研究目标、硬约束、方法/软件偏好、待验证的创新想法
已核验的官方规则链接/文件：
缺失字段分级：当前任务必需 / 可假设的设计条件 / 优化偏好
本轮交付物：
```

字段分级说明：

- **阶段相关字段**：报名、知识赛、组队无需先有选题；选题阶段可比较候选问题与总体。调查设计前需明确研究问题与对象，实证结论需真实数据和诊断。只补问当前任务所需字段，继续可执行的准备工作。
- **设计字段**：地域、样本计划、数据来源、比赛规则。缺失时可给条件化方案，但必须标注假设。
- **优化字段**：软件偏好、版式偏好、团队分工。缺失时采用默认值并说明。
