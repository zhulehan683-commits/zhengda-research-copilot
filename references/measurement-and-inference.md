# 从问卷到可解释结论

进入调查设计、清洗或统计分析时按对应小节使用。本文件整合了 MIT 许可的 questionnaire-analysis-skill 的清洗、测量诊断与报告框架，并按竞赛证据链作适配；不是所有项目都要做因子分析或 SEM。

## 1. 先冻结分析合同

每个研究问题先填写 `templates/analysis-contract.csv`：目标人群与渠道、分析单位、结果变量、解释/分组变量、测量尺度、主要分析、缺失与排除规则、估计量、诊断、稳健性方案。探索性分析与事先计划分开标记；看过结果才改变的规则保留变更理由。

问卷审核使用 `templates/questionnaire-review.csv`。逐题核对构念、对象、回忆时间窗、选项覆盖、跳题逻辑与编码；一题只问一个问题。行为、购买意愿与实际购买分别记录，不能互相代替。多选题要明确“选项选择次数”与“受访者人数”两个分母，比例之和可能超过 100%。

反向题不靠模型猜测；量表授权/来源、原题、中文修订、适用对象和预测试记录进入证据表。预调查同时检查题意、手机显示、跳题和数据导出，修订后保留新旧版本及变更原因。

## 2. 数据预检与清洗

1. 原始 CSV 放在项目 `raw_private/`，保留只读来源、问卷版本与哈希；先确认编码和一行的分析单位。
2. 根据实际字段改写 `templates/data-preflight-schema.json`，复制到工作区，运行 `scripts/survey_audit.py`。它输出必填缺失、类型、范围、重复标识与行结构的汇总计数，不输出原始回答或受访者标识，也不修改数据。
3. `BLOCKED` 表示需要解释或修复输入后复核；`READY_FOR_REVIEW` 只是结构预检通过。重复编号应先判断追访、多波次、同户或真正重复，不能直接删；同样答案和短时长也是待核查信号，不能单独证明无效回答。
   诊断文件只允许新建在 `analysis/` 下；已有同名输出会拒绝覆盖，重跑时换一个文件名。不能把 `state/`、`tasks/` 或原始数据作为输出位置。
4. 清洗规则写进脚本；分别记录初始记录数、重复/不符合总体/缺失等处置数、最终样本数及各分析有效样本数。只对分析副本处理，不覆写源数据。
5. 反向计分使用原量尺下界 L、上界 U：`新分 = L + U - 原分`；先识别缺失码，再转换有效回答。原题和新变量分开保存，避免重复反向。
6. 报告变量级和个案级缺失、跳题产生的结构性缺失。不能仅凭“小于某比例”选择删除或均值填补；Little 检验不显著不能证明 MCAR，也不能靠它区分 MAR/MNAR。插补/FIML 需要与变量类型、模型和缺失假设相容，并比较敏感性结果。

预检仅支持 CSV 的字符串/数值/整数与范围合同；多选拆分、复杂跳题、反向计分、量表合成、统计检验交由经审查的分析代码实现。Excel/SPSS/MATLAB 数据须先在获准环境导出保留编码信息的 CSV。

## 3. 测量模型按数据条件选择

| 场景 | 合理动作 | 需要保留的证据 |
| --- | --- | --- |
| 事实/行为单题 | 检查内容、编码与测量误差；通常无需内部一致性系数 | 题项、观察窗口、分布、外部核对 |
| 多题反映式量表 | 按构念检查维度、反向题、内部一致性；可用 α/ω，模型合适时报告 CR | 题项数、估计方法、相关/载荷、置信区间与内容理由 |
| 自编或大幅改编量表 | 数据足够时探索因子结构；用平行分析、理论和可解释性共同选因子 | 相关矩阵、提取与旋转方法、载荷/交叉载荷及修订日志 |
| 已有理论结构 | 在模型可识别且样本信息充分时做 CFA，必要时用适合有序题项的估计器 | 拟合指标、异常解、载荷、误差、收敛/区分效度与估计设置 |
| 样本不足或结构不稳定 | 保留题项级描述与探索性关联，补采样或缩小问题 | 限制与降级说明；不能因 SEM 做不了就认定 EFA 一定可做 |

PCA 是降维，不等同于潜在因子模型；α 高不证明单维性或效度。ω、CR、AVE、KMO、拟合指数等不能脱离模型假设机械打勾。删题必须同时有内容和测量依据，保留删前删后结果；不能仅为提高 α 或“拟合达标”修改模型。同批数据做 EFA 后再做 CFA，只能称内部探索/拟合；需独立或预留样本才有更强验证证据，且不能为形式折半导致两边都不足。

共同方法偏差优先在题目、来源和时间安排中控制。Harman 单因子、潜方法因子或其他单项诊断均不能证明“无共同方法偏差”；横断面中介路径也不能自行证明时间顺序与因果机制。

## 4. 统计推断的边界

- 便利、滚雪球和配额招募属于非概率样本：先描述覆盖与选择机制；经典随机抽样误差范围不能直接写成总体代表性保证。模型或 bootstrap 区间只刻画其假设下的不确定性，不能消除未观测选择偏差。
- 将范围从“全国”缩小到“本校”或“本渠道”不会自动建立代表性；无可识别抽样/选择模型时，表述为“本次受访样本中”，不声称代表所有可触达学生。样本量方案先列精度、设计效应、有效回收率等待确定参数，不能主动把一组经验参数当作该项目的固定要求。
- 概率抽样需要保留分层、整群、抽样概率与权重。学校/班级/门店内相关、配对或重复测量应在方差估计或模型中处理，不能把所有行当独立样本。
- 先确定主要结果和比较族，报告多重比较处理；同时给估计值、效应量、区间和有效样本量。零结果保留；不以 p 值是否跨阈值筛选结果。
- 描述相关、解释与预测分开。预测模型先划分验证方案，插补、标准化、特征筛选只在训练折内拟合；特征泄露会让性能虚高。
- 软件按团队选择 Python/R/SPSS/AMOS/MATLAB；记录版本、依赖、随机种子、执行命令和日志。安装本 skill 不会安装这些统计环境。

## 5. 输出合同

每张结果表至少有 `RQ/假设 → 方法与诊断 → 数据/脚本哈希 → 估计值及单位 → 有效 N/分母 → 区间/效应量 → 限制 → 行动`。表头可先提供占位字段；真实数值只能来自已复核计算。建议说明责任人、具体动作、资源前提、时间和衡量指标。

精确 p 值来自软件输出；小于显示精度时用合适的上界，例如 `p < .001`，不写 `p = .000`。版式按当届报告要求；中文报告无需强制双语，标准化回归系数可能超出 [-1, 1]，不能套用相关系数的取值规则。
