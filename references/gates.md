# 阶段质量门禁（机械 + 专业两层）

## 机械门禁（命令行验证）

`workflow.py gate` 校验该阶段必要的键、普通文件存在、路径位于项目根目录内、SHA-256 未变化，以及前序阶段的 `passed` 状态；失败即 `BLOCKED`。路径穿越和符号链接会被拒绝。`fieldwork` 的 `raw_dataset` 必须位于工作区 `raw_private/` 下。`workflow.py review` 记录独立复核结果，传入审查者称呼与证据说明。该记录仅证明**有人填写了记录**，不自动证明身份或结论有效。

## 专业复核清单

| 门禁 | 核验问题 | 必须报告为 BLOCKED 的示例 |
|---|---|---|
| K | 本人真实通过知识赛吗？ | 无真实成绩或资格证明 |
| T | 选题符合当届组别与企业命题限制吗？ | 无学校/赛区规则 |
| D | 抽样框覆盖总体吗？题目有效吗？ | 用便利样本声称代表全部群体 |
| F | 有真实同意、调查记录和原始数据吗？ | 虚构受访者、自动生成问卷结果 |
| C | 清洗规则预先定义、删除样本留痕吗？ | 为追求显著性任意删数据 |
| A | 每个统计结论可复现且适配数据吗？ | 未核验模型假设、夸大因果 |
| R | 每条结论有结果表/原始来源/合理限制吗？ | 仅凭 AI 生成的文字和数字 |
| P | 演示文稿与报告、代码一致吗？ | PPT 独立生成不同数字 |
| S | 提交格式与当届官方规则一致吗？ | 依靠往届页数要求或他校通知 |

## 真实数据 / 伦理硬约束

- 原始数据不可为获奖或显著性随意更改；不伪造问卷、回收率、Cronbach α、KMO、p 值、模型参数或访谈原话。
- 对姓名、联系电话、学号、精确住址等信息脱敏；按收集许可限制访问，原始数据留在本地受控目录。不向未授权云平台上传问卷原件。
- 采集在线评论/用户数据应遵守网站条款、隐私法律、授权边界，不绕过访问控制。
- 文献综述不等于证据：每条关键统计或市场事实需原始出版方与时间、统计口径。
- 统计方法按问题/变量/尺度/抽样设计选择。没有真实数据时只能给分析计划、空表和代码骨架。

## 数据变化的失效机制

修改上游任何**绑定证据**，先前 `passed` 状态及全部下游 `passed` 状态均失效。这是保守策略，可能造成额外复审，但不会继续沿用旧结果。脚本无法感知**未绑定文件**变化，关键数据和代码必须绑定到相应键。

## 审计回执模板

```text
Gate: A / report
Reviewer: [须不同于被审产物作者]
Input file SHAs: ...
State: PASS / FAIL / BLOCKED
Evidence: 文件路径、公式编号、运行命令、退出码、关键数值
Critical issues: ...
Required rework: 执行人、复现步骤、影响范围
Review time: UTC timestamp
```
